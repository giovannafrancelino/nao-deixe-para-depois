# Não Deixe pra Depois 🚀

Plataforma web desenvolvida para auxiliar colaboradores (no contexto da CDIAL HALAL) a organizarem suas metas de saúde preventiva e autocuidado de forma prática, gamificada e totalmente privada.

🔗 **Acesse a aplicação online:** [https://giovannafrancelino.github.io/nao-deixe-para-depois/](https://giovannafrancelino.github.io/nao-deixe-para-depois/)

---

## 💡 Sobre o Projeto
O projeto nasceu da necessidade de criar um plano de ação imediato para a saúde preventiva sem burocracias, palestras cansativas ou invasão de privacidade. A ferramenta utiliza uma interface em **Wizard (passo a passo)** para guiar o usuário na criação de metas de autocuidado, recompensas e agendamento integrado, sem que nenhum dado médico sensível ou exame seja armazenado pela empresa.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização responsiva e moderna)
* **JavaScript** (Lógica de navegação em etapas, manipulação do DOM e interatividade)

## 🎯 Principais Funcionalidades
* **Jornada em Wizard:** Navegação fluida tela por tela para facilitar o preenchimento.
* **Gamificação e Recompensas:** Incentivo ao cumprimento das metas pessoais de saúde.
* **Privacidade Absoluta (LGPD):** Foco estrito no progresso do usuário, sem exposição de dados pessoais ou laudos médicos.
* **Integração com Calendário:** Facilidade para agendar os compromissos de autocuidado.
